## Base URL

All requests are made to `https://api.acme.dev/v1`. Requests over plain HTTP are rejected.

## Rate limits

Each API key may make **100 requests per second**. Exceeding the limit returns HTTP `429 Too Many Requests` with a `Retry-After` header.
