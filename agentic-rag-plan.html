Ingestion reads your MDX directly

No export needed — ingestion script reads your content/ folder as-is. 

// ingestion/parsers/mdx.ts
import matter from 'gray-matter'
import { readFileSync } from 'fs'

export function parseMDXFile(path: string) {
  const raw = readFileSync(path, 'utf-8')
  const { data, content } = matter(raw)
  return {
    title: data.title,
    slug: data.slug,
    content,
    lastModified: data.date,
  }
}

// app/api/chat/stream/route.ts
export async function POST(req: Request) {
  const res = await fetch(
    `${process.env.BACKEND_URL}/chat/stream`,
    {
      method: 'POST',
      body: req.body,
      headers: req.headers,
    }
  )
  return new Response(res.body, {
    headers: { 'Content-Type':
                'text/event-stream' },
  })
}

## Ingestion Pipeline Requirements
📄Parse MDX files using gray-matter — extract frontmatter: title, slug, description
🧹Strip MDX/JSX syntax, keep clean markdown text
✂️Chunk semantically — split on H2/H3 headings, keep heading as chunk title prefix
🎯Target: 512 tokens per chunk, 64-token overlap
🏷️Metadata per chunk: { title, slug, heading, url, contentHash, lastModified }
🔢Embeddings: text-embedding-3-large via OpenAI
💾Upsert to pgvector — skip if contentHash unchanged (idempotent)
🔍Index text in Typesense for BM25
▶️Run as: npx ts-node src/ingestion/pipeline.ts --source ../docs/content
## Agentic Loop Requirements Use OpenAI function calling (not LangChain) to keep it lean:
const tools = [ { name: "search_docs", description: "Search documentation by semantic meaning and keywords", parameters: { query: string, top_k?: number } }, { name: "get_page", description: "Get the full content of a specific doc page by its slug", parameters: { slug: string } }, { name: "search_code_examples", description: "Search specifically for code examples and snippets", parameters: { query: string } } ]
🔄Loop: GPT-4o calls tools → execute → append result → repeat until no more tool calls → stream final answer
🛑Max iterations: 5 (prevent runaway loops)
⚡Router: short/simple query → skip agent, do 1-pass RAG directly (saves tokens)
## Hybrid Search Requirements
Step 1Embed the query with text-embedding-3-large
Step 2Run pgvector cosine similarity search → top 20 results
Step 3Run Typesense BM25 search → top 20 results
Step 4Merge and deduplicate by slug (keep higher score)
Step 5Fusion: score = 0.6 * vectorScore + 0.4 * bm25Score
Step 6Pass top 20 to Cohere Rerank → return top 5
Returns{ content, title, slug, url, score }[]
## SSE Streaming Endpoint
POST /chat/stream  ·  Request: { message: string, sessionId: string }  ·  Response: text/event-stream
// Stream event types — compatible with Vercel AI SDK useChat data: {"type":"token","content":"..."} // each LLM token data: {"type":"tool_call","tool":"search_docs"} // agent thinking data: {"type":"sources","data":[{url,title}]} // citations data: {"type":"done"} // end of stream
## Conversation Memory
🔑Redis key: chat:session:{sessionId}
💾Store last 10 turns as JSON array (sliding window)
⏱️TTL: 24 hours per session
📖Include full history in every LLM call for context continuity
